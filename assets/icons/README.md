# ไอคอนของ Birthday Quest

เก็บไฟล์ไอคอนที่ใช้ในเว็บไซต์ไว้ในโฟลเดอร์นี้ แนะนำให้ใช้ SVG สำหรับไอคอนเวกเตอร์ และ PNG สำหรับภาพไอคอนที่มีรายละเอียดหรือพื้นหลังโปร่งใส

## วิธีเพิ่มไอคอน

1. ดาวน์โหลดไฟล์ไอคอนจากแหล่งที่อนุญาตให้ใช้งาน
2. วางไฟล์ไว้ในโฟลเดอร์นี้ และตั้งชื่อให้สื่อความหมาย เช่น `quest.svg`, `gift.svg` หรือ `controller.png`
3. เพิ่มรายละเอียดผู้สร้างและ license ใน `CREDITS.md`
4. เรียกใช้ในหน้าเว็บด้วยคลาส `game-icon` ซึ่งกำหนดขนาดและการจัดแนวไว้ใน `icons.css`

ตัวอย่าง:

```html
<img class="game-icon" src="assets/icons/controller.svg" alt="เกม">
```

ตรวจสอบ license ของไฟล์แต่ละชิ้นก่อนนำมาใช้ เพราะแต่ละเว็บไซต์และแต่ละไอคอนอาจกำหนดเงื่อนไขต่างกัน
